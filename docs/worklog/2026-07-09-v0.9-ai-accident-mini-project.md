## README에서 확인한 내용

- AI 기반 도로 낙하물 탐지 및 위험 알림 시스템.
- 이미지/영상 업로드 시 YOLO 기반 객체 탐지 수행.
- 낙석, 박스, 타이어 등 객체 분류.
- 위험/긴급 상황 실시간 알림.
- 지도 기반 위험 위치 시각화.
- 경로 기반 위험 분석.
- 신고 기능, 관리자 기능, LLM 자동 생성, AI 분석 비교.
- Flask, SQLAlchemy, Flask-Migrate, Flask-SocketIO, HTML/CSS/JavaScript, Google Maps API, Kakao Navigation API, YOLOv8, YOLOv8-p2, RT-DETR, LLM, MySQL 사용.

## 역할 반영 기준

- 사용자가 제공한 기준에 따라 `송명근 / 조원 / 팀원`으로 표현했다.
- README의 직책 표현과 별개로 포트폴리오에는 조원 / 팀원 기준으로 정리했다.
- 신고 기능 구현, Google Maps API 연동, AI 탐지 기능 개발 및 서비스 연계 참여를 역할로 정리했다.
- LLM 기반 신고 제목/내용 보조 기능 참여는 README 확인 범위 안에서 표현했다.
