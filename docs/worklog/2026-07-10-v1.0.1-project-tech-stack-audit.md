## 실제 확인 근거

- STACCATO README: YOLOv11, Flask API Gateway, MySQL, Socket.IO, FastAPI AI service, VM 분리 구조.
- STACCATO 기존 v0.10 문서: AI Media Proxy, Nginx, systemd, 운영 흐름.
- Wizard Defense 기존 문서: Unity, C#, Unity 기반 2D PC / Steam 지향 프로토타입.
- Inquiry Dataset README와 코드: CSV, dataclass, rule classifier, TF-IDF, LogisticRegression, scikit-learn, dataset card, labeling guide, experiment/error analysis, test script.
- 404 R·N·F AI README: Flask, SQLAlchemy, Flask-Migrate, Flask-SocketIO, HTML/CSS/JavaScript, Google Maps API, Kakao Navigation API, YOLOv8, YOLOv8-p2, RT-DETR, LLM, MySQL, WebSocket, file upload, route risk analysis.

## 추가하지 않은 후보

- STACCATO SQLAlchemy / ORM: 확인 근거 부족.
- Wizard Defense SpriteRenderer, Animator, TextMeshPro / TMP, Unity UI, Tile / Grid System, ScriptableObject, Coroutine: 확인 근거 부족.
- Inquiry Dataset pytest: 확인 근거 부족.

## 유지한 내용

- 프로젝트 설명 본문은 불필요하게 수정하지 않았다.
- GitHub Pages 배포 설정, `vite.config.ts`, workflow를 변경하지 않았다.
- 이력서 PDF, 인크루트 링크, 이메일, 희망 직무 설정을 유지했다.
- 사진/수료증 직접 노출 제거 상태를 유지했다.

- build: `npm.cmd run build` 통과
