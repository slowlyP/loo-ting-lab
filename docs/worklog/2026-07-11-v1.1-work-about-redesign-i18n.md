# v1.1 Work / About / Project Detail Redesign + KO/EN Worklog

## Summary

The portfolio moved from the dark Lab Browser presentation to a bright Work Gallery. The previous concept was distinctive, but its OS/HUD framing competed with project content. The new design prioritizes project context, contribution boundaries, evidence, typography, and reading flow.

## Work Gallery

- Replaced the compact three-column archive with a responsive two-column gallery.
- Added CSS-based abstract project thumbnails because verified screenshots are not available for every project.
- Improved card hierarchy for category, status, title, subtitle, summary, technology, and the case-study action.
- Made `/` render the same selected-work experience while retaining the existing route.
- Added a desktop hover preview state with a stronger border/shadow, subtle thumbnail movement, and a case-study overlay.
- Added a separate `projectPreviews.ts` registry so image and MP4 paths can be connected later without changing project facts.
- Kept every current project on the CSS abstract fallback because no verified preview asset exists yet.
- Prepared safe image/video error fallback and hover-only muted video playback; touch devices remain static.
- Reduced-motion users do not receive thumbnail scaling/translation or automatic video playback.

### Adding future preview assets

- Place verified files under `public/assets/projects/<project-id>/`.
- Set the matching preview entry to `kind: 'image'` with `image: 'assets/projects/...'`, or `kind: 'video'` with `video: 'assets/projects/...'`.
- The preview helper prepends `import.meta.env.BASE_URL`, so the same relative entry works with the existing GitHub Pages repository base path.
- Video elements are created only for video entries and use `muted`, `loop`, `playsInline`, and `preload="metadata"`.

## KO/EN architecture

- `LanguageContext.tsx` owns state, persistence, document language, and Korean UI fallback.
- `useLanguage.ts` contains the shared context/hook and storage key.
- `translations.ts` contains common UI, Work, About, Detail, and footer copy.
- `projectTranslations.ts` stores English project copy by original project ID and merges it over unchanged source projects.
- The localStorage key is `loo-ting-lab-language`; only `en` is accepted as an alternative, so missing or invalid values resolve to `ko`.
