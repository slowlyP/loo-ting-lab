# v1.2 Dark Mode + Network Background Tuning Worklog

## Summary

Added an explicit light/dark theme while preserving the bright Work Gallery as the default. Dark mode uses deep navy and translucent slate surfaces so it feels like the same portfolio rather than a return to the previous Lab Browser design.

## Theme architecture

- `theme/types.ts`: `Theme = 'light' | 'dark'`.
- `theme/useTheme.ts`: context, hook, and `loo-ting-lab-theme` key.
- `theme/ThemeContext.tsx`: state, persistence, light fallback, root `data-theme`, and `colorScheme`.
- `components/ThemeToggle.tsx`: localized accessible control using existing react-icons.
- ThemeProvider and LanguageProvider are independent and nested at the application root.

## Persistence

- Light is the initial default to preserve v1.1 appearance.
- Only `dark` is accepted from storage; every other value falls back to light.
- The selected value is written on theme changes and restored on refresh.

## Dark styling

- Added light/dark CSS variables for page background, glows, surfaces, borders, text, and accent colors.
- Added a data-theme Tailwind dark variant.
- Applied dark styling to the app shell, navigation, toggles, Footer, Work groups/cards, About, Project Detail, preview fallbacks, and technology badges.
- Kept real preview images undimmed and improved image-title contrast.
- Resume and Contact retain their existing dark panels and remain readable through direct routes.

## Network background

- Increased point radii from 1.3/1.7 to 1.65/2.15 in light and 1.75/2.25 in dark.
- Increased line width from 0.65 to 0.75 and maximum opacity from 0.115 to 0.17 light / 0.20 dark.
- Increased triangle fill to 0.032–0.038 light and 0.038–0.046 dark.
- Used slate/muted violet in light and blue-gray/soft lavender in dark.
- Preserved point counts, distances, pointer behavior, mobile throttling, DPR cap, reduced motion, animation loop, and cleanup.

## Preserved v1.1 work

- KO/EN toggle and Korean fallback.
- Work Gallery and Team/Personal grouping.
- Project previews and abstract fallback.
- STACCATO/404 live sites and preview images.
- Ownership labels and 404 presentation PDF.
- HashRouter and Resume access.
