# v1.0 GitHub Pages Deploy Worklog

## 작업 날짜

- 2026-07-10

## 브랜치

- feature/v1.0-github-pages-deploy

## 작업 목표

- Loo Ting Lab 포트폴리오를 GitHub Pages로 배포할 수 있도록 준비한다.
- 예상 배포 URL은 `https://slowlyp.github.io/loo-ting-lab/`이다.
- GitHub Pages 저장소 하위 경로 배포에 맞게 Vite base와 public asset URL을 정리한다.

## 변경 내용

- `vite.config.ts`
  - GitHub Pages 하위 경로 배포를 위해 `base: '/loo-ting-lab/'`를 추가했다.
- `src/data/resume.ts`
  - Resume PDF URL을 고정 절대 경로 `/assets/resume/documents/resume.pdf`에서 `import.meta.env.BASE_URL` 기반 URL로 변경했다.
  - 배포 후 PDF 예상 경로는 `https://slowlyp.github.io/loo-ting-lab/assets/resume/documents/resume.pdf`이다.
  - 로컬 개발 환경에서는 `/assets/resume/documents/resume.pdf`로 접근된다.
- `.github/workflows/deploy.yml`
  - GitHub Pages 배포 workflow를 추가했다.
  - main 브랜치 push와 수동 실행을 지원한다.
  - `npm ci`, `npm run lint`, `npm run build` 후 `dist`를 Pages artifact로 업로드하고 배포한다.
- `README.md`
  - GitHub Pages 배포 URL을 추가했다.
- `docs/VERSION_PLAN.md`
  - v1.0 Release Preparation에 GitHub Pages Deploy 내용을 추가했다.
- `docs/change-request/2026-07-10-v1.0-github-pages-deploy-request.md`
  - v1.0 작업 요청 문서를 생성했다.
- `docs/validation/2026-07-10-v1.0-github-pages-deploy-validation.md`
  - v1.0 검증 문서를 생성했다.
- `docs/release/v1.0.md`
  - v1.0 release 문서를 생성했다.

## 유지한 내용

- 기존 HashRouter 라우팅을 유지했다.
- 프로젝트 내용과 디자인은 변경하지 않았다.
- 이력서 PDF, 인크루트 링크, 이메일, 희망 직무 설정은 유지했다.
- 사진/수료증 직접 노출 제거 상태를 유지했다.

## 검증 결과

- lint: `npm.cmd run lint` 통과
- build: `npm.cmd run build` 통과
- `dist` 폴더 생성 확인
