# v1.3.2 Wizard Defense Visual Gallery Worklog

## Summary

Added a Random Wizard Defense-only horizontal Visual Gallery directly below the existing Hero gameplay video.

## Gallery data

- Added `projectGalleries.ts` with a typed `wizard-defense` gallery.

- Added Korean/English captions, stable alt text, categories, and GitHub Pages BASE_URL resolution.

## Interaction

- Added mouse pointer drag using start position and start scroll offsets.
