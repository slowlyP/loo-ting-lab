- 고속도로 CCTV 기반 차량 탐지.
- YOLOv11 기반 객체 탐지.

- Flask API Gateway와 MySQL 메타데이터 저장.
- Socket.IO 기반 실시간 알림.
- Next.js 관제 화면.
- 신고 업로드 / 신고 분석.
- Snapshot / MP4 Replay.
- 인증 기반 AI media proxy.
- Frontend VM / Flask VM / AI VM / DB VM 분리 구조.
- 회원가입 승인과 권한 기반 접근 정책.

## 변경 내용

- `src/data/projects.ts`
  - STACCATO 항목에 `detail` 데이터를 추가했다.
  - 프로젝트 개요, 해결하려는 문제, 아키텍처 / 데이터 흐름, 내가 맡은 역할, 구현 상태 구분, 기술스택, 문제 해결 / 설계 포인트, 결과 및 배운 점을 복구했다.
  - 확인된 GitHub 저장소와 YouTube 시연 영상 링크를 연결했다.
  - 직접 구현이 확실하지 않은 항목은 참여 / 검증 / 구조 정리 표현으로 작성했다.
- `src/pages/ProjectDetail.tsx`
  - STACCATO 상세에서 핵심 구조 섹션 제목이 `아키텍처 / 데이터 흐름`으로 보이도록 조정했다.
- `docs/VERSION_PLAN.md`
  - v0.10 STACCATO Detail Completion 계획을 추가했다.
