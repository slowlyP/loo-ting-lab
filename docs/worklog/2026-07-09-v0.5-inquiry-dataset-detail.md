## Confirmed Project Facts

- Dataset v1 contains 100 synthetic Korean inquiries.
- Dataset v2 contains 150 synthetic Korean inquiries.
- Label fields are `id`, `text`, `category`, `subcategory`, `urgency`, and `needs_human`.
- v0.4 rule baseline accuracy is 60.00% on the 100-row v1 dataset.
- v2 baseline results are rule-based 44.67% and TF-IDF 72.67%.
- improved rule v2 is 94.00% on the v2 dataset, but this is not presented as generalization performance.
- `python backend/scripts/test_rule_classifier.py` passes in the inspected repository.
