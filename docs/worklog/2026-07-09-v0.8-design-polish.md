## 변경 내용

- `Header`
  - nav 문구를 정상 한국어로 정리.
  - sticky header, active/hover/focus 스타일 개선.
- `Footer`
  - 버전 표기를 `v0.8 polish`로 정리.
  - 깨진 설명 문구를 정상 한국어로 수정.
- `Hero`
  - v0.8 기준 Mission Board 문구로 정리.
  - CTA 버튼 간격과 모바일 세로 배치를 개선.
  - 정보 카드 간격과 텍스트 계층을 정리.
- `ProjectBrowser` / `ProjectCard`
  - 목록 헤더 문구 정리.
  - status badge, tech badge, detail button의 대비와 간격 개선.
- `ProjectDetail`
  - 깨진 섹션 제목과 버튼 문구 정리.
  - 섹션 카드, 상태 카드, 산출물 카드, 링크 영역의 스타일 톤 통일.
  - 기존 프로젝트 핵심 설명 데이터는 유지.
- `Resume` / `About` / `Contact`
  - 깨진 한국어 문구를 정상 한국어로 정리.
  - 카드 스타일과 섹션 간격을 통일.
  - Contact 링크 버튼의 줄바꿈과 가독성 개선.
- `index.css`
  - selection 색상과 링크 줄바꿈 기본값 추가.

## 유지한 내용

- 라우팅 구조는 변경하지 않았다.
- 외부 이미지, 영상, 링크를 임의로 추가하지 않았다.
- 개인정보, 이메일, 학력, 경력을 임의로 만들지 않았다.
- Wizard Defense의 PC / Steam 지향 표현은 유지했다.
- Inquiry Dataset의 합성 데이터 제한과 추가 검증 필요 표현은 유지했다.
- STACCATO의 확인되지 않은 기여를 과장하지 않았다.
