## 작업 목표

- Resume 페이지를 취업용 이력서 형태로 고도화한다.
- 증명사진, 희망 직무, 교육받은 내용, 자기소개 요약, 자기소개 자세히 보기 영역을 추가한다.
- 확인되지 않은 개인정보는 임의로 만들지 않고 추가 예정 / 정리 예정으로 표시한다.

## 변경 내용

- `src/pages/Resume.tsx`
  - 증명사진 / 기본 정보 영역 추가.
  - 증명사진 placeholder와 3:4 비율, 300x400px 또는 360x480px 권장 크기 안내 추가.
  - 희망 직무 섹션 추가.
  - Profile Summary, Core Skills, Project Experience, Education / Training, 자기소개 요약, Links / Contact 섹션으로 재구성.
  - 자기소개 자세히 보기 접기 / 펼치기 UI를 `useState`로 구현.
  - Core Skills와 Project Experience의 기술 태그에 `TechStackBadges` 재사용.
- `src/index.css`
  - Noto Sans KR을 CSS import 방식으로 적용.
  - font-family fallback을 system UI 계열과 함께 설정.
- `docs/VERSION_PLAN.md`
  - v0.11 Resume / Cover Letter Page Upgrade 계획 추가.
