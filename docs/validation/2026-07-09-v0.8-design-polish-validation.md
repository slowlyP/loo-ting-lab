## 모바일 반응형 확인 결과

- Header nav는 flex-wrap으로 작은 화면에서 줄바꿈 가능.
- Hero CTA는 작은 화면에서 세로 배치, sm 이상에서 가로 배치.
- ProjectCard grid는 기존 lg 3열, 작은 화면 1열 유지.
- ProjectDetail의 구현 상태 3열 카드는 lg 이상 3열, 작은 화면 1열 유지.
- Contact 링크 버튼은 `max-w-full`과 `break-words`로 긴 링크/텍스트 줄바꿈 대응.

## 깨진 문구 검색 결과

- `src/components`, `src/pages` 기준으로 대표 mojibake 문자열 검색 결과 없음.

## 남은 문제

- 브라우저 실제 화면 캡처 검증은 수행하지 않았다.
- v0.8은 디자인 polish 단계이며, 실제 이미지/영상 자산 추가는 이후 작업으로 남겨두었다.
