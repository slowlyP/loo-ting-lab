## ProjectCard preview 개선

- ProjectCard에서 `project.tech` 표시 제한을 4개에서 8개로 늘렸다.
- 남은 기술스택이 있으면 `+N modules` badge를 표시한다.
- `TechStackBadges`에 `showMoreCount`와 `moreLabel` 옵션을 추가했다.
- ProjectDetail은 `limit` 없이 기존처럼 전체 기술스택을 표시한다.
- badge container는 `flex flex-wrap gap-2`를 유지하므로 모바일에서도 자연스럽게 줄바꿈된다.
