# v0.7 Release Notes

## Version

- v0.7 Wizard Defense PC / Steam Direction

## Summary

- Wizard Defense 프로젝트 상세 문구를 최신 Notion 기획 방향에 맞춰 PC / Steam 지향으로 수정했다.
- 기존 v0.4에서 모바일 가로형으로 정리했던 현재 노출 문구를, Notion에서 확인한 PC / Steam 방향성 기준으로 갱신했다.
- 과거 v0.4 문서는 당시 기록으로 유지하고, 이번 v0.7 문서에 방향성 변경 내역을 남겼다.

## Changes

- Wizard Defense를 `Unity 기반 2D PC / Steam 지향 캐주얼 판타지 타워디펜스 프로토타입`으로 설명.
- `Steam 출시를 목표로 방향성을 전환 중`인 상태로 표현.
- `플레이 가능 프로토타입 단계` 표현 유지.
- 일반 마법사 융합, 속성 융합, 전설 마법사와의 시너지 실험을 핵심 재미로 강조.
- `Mobile Landscape` 태그를 `PC / Steam Direction`으로 수정.
- 확인되지 않은 Steam 페이지나 데모 URL은 만들지 않고 추가 예정으로 표시.
- `docs/VERSION_PLAN.md`에서 v0.7, v0.8, v0.9 계획을 현재 흐름에 맞게 조정.

## Verification

- lint: `npm.cmd run lint` 통과
- build: `npm.cmd run build` 통과

## Notes

- Steam 출시 완료, 상용 출시 게임, 정식 출시작, 출시 준비 완료 같은 표현은 사용하지 않았다.
- v0.4 release/worklog/change-request/validation 문서는 직접 수정하지 않았다.
