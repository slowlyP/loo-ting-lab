# v0.10 Release Notes

## Version

- v0.10 STACCATO Detail Completion

## Summary

- STACCATO 상세 페이지에 누락되어 있던 v0.3 상세 내용을 복구했다.
- STACCATO GitHub 저장소 README와 관련 docs에서 확인한 기술 구조를 현재 포트폴리오 데이터 구조에 맞게 보강했다.
- 개인 기여를 과장하지 않도록 참여, 검증, 구조 정리, 연동 흐름 확인 중심의 문장으로 작성했다.

## Changes

- STACCATO 상세 데이터 추가.
- 고속도로 CCTV 기반 차량 탐지, YOLOv11, bbox 중심점 이동량 기반 정차 추정, ROI / Rule Engine, LANE_STOP / SHOULDER_STOP 설명 추가.
- AI VM -> Flask API Gateway -> MySQL -> Socket.IO -> Next.js 관제 화면으로 이어지는 데이터 흐름 추가.
- Snapshot / MP4 Replay, 신고 업로드 / 신고 분석, 인증 기반 AI media proxy 설명 추가.
- 관리자 회원 승인과 권한 기반 접근 정책을 확인된 범위에서 반영.
- GitHub 저장소와 확인된 YouTube 시연 영상 링크 추가.
- STACCATO 상세의 핵심 구조 섹션 제목을 `아키텍처 / 데이터 흐름`으로 표시.
- `docs/VERSION_PLAN.md`에 v0.10 계획 추가.

## Verification

- lint: `npm.cmd run lint` 통과
- build: `npm.cmd run build` 통과

## Notes

- 상용 운영 완료 또는 단독 전체 개발처럼 보이는 표현은 사용하지 않았다.
- 공개 서비스 링크는 자체서명 인증서가 안내된 개발/시연 환경이므로 포트폴리오에는 직접 노출하지 않았다.
