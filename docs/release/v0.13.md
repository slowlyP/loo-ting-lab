# v0.13 Release Notes

## Version

- v0.13 Unique Lab Browser Concept

## Summary

- 포트폴리오 전체 컨셉을 `Loo Ting Lab OS`, `Developer Lab Browser`, `Project Archive System` 쪽으로 정리했다.
- 흔한 판타지 RPG 메뉴 느낌을 줄이고 개발 연구소 브라우저, 프로젝트 파일, 실험 기록, 콘솔 HUD 느낌을 강화했다.
- 프로젝트 설명과 사실 관계는 유지하고 UI 레이블과 스타일 중심으로 개선했다.

## Changes

- 전역 배경에 은은한 grid / scanline texture 추가.
- Header / Footer 브랜드를 Loo Ting Lab OS 흐름으로 정리.
- Home Hero를 Lab Browser 메인 콘솔 느낌으로 변경.
- Projects / ProjectBrowser를 Project Archive System 문맥으로 변경.
- ProjectCard를 Experiment File / FILE 카드 느낌으로 변경.
- ProjectDetail에 Project File, Experiment Brief, System Modules, External Access, Repository Access 레이블 적용.
- Resume을 Developer Character Sheet 문맥으로 정리.
- About을 Lab Profile 문맥으로 정리.
- Contact를 Contact Portal 문맥으로 정리.
- Resume에서 증명사진과 수료증 직접 노출 제거.
- `/assets/resume/documents/resume.pdf`로 연결되는 이력서 PDF 접근 버튼 추가.
- 실제 이메일 `vvckfn@gmail.com`과 mailto 링크 반영.
- Education / Training에 `한국IT전문대학 게임그래픽학과 중퇴`, `학점은행제 컴퓨터공학학과 진행중` 반영.
- `profile-photo.jpg`와 `certificate-01.pdf`를 Git 추적 대상에서 제거.
- `public/assets/resume/documents/.gitkeep` 추가.
- `docs/VERSION_PLAN.md`에 v0.13 계획 추가.

## Verification

- lint: `npm.cmd run lint` 통과
- build: `npm.cmd run build` 통과

## Notes

- `src/data/projects.ts`는 수정하지 않았다.
- v0.12 Resume 사진 / 수료증 직접 노출은 개인정보 노출을 줄이기 위해 제거했다.
- 실제 이력서 PDF는 아직 파일이 없으므로 planned 상태로 표시한다.
- 기존 프로젝트 설명을 임의로 크게 바꾸지 않았다.
## Additional Resume Access Update

- 증명사진 / 수료증 직접 노출 제거 상태를 유지했다.
- 실제 이력서 PDF를 `/assets/resume/documents/resume.pdf` 경로로 연결했다.
- Resume 페이지와 Contact 페이지에서 이력서 PDF를 새 탭으로 열 수 있게 했다.
- 인크루트 이력서 확인 링크를 보조 링크로 추가했다.
- 이력서 PDF는 public assets에 포함되므로 배포 후 공개될 수 있다. 개인정보가 포함된 PDF는 공개 전 민감정보 포함 여부를 확인해야 한다.

## Additional Resume Direction Update

- Resume의 희망 직무를 프론트엔드 중심 표현에서 AI 모델 개발, AI 기반 서비스 구현, Unity 기반 게임 기획·개발 중심으로 수정했다.
- React / TypeScript 경험은 주력 희망 직무가 아니라 보조 서비스 화면 구현 경험으로 정리했다.
- AI 프로젝트, 데이터셋 프로젝트, Unity 게임 프로젝트 경험이 희망 직무와 연결되도록 Resume / About / Contact 문구를 일부 조정했다.
