# v0.11 Release Notes

## Version

- v0.11 Resume / Cover Letter Page Upgrade

## Summary

- Resume 페이지를 취업용 이력서 형태로 고도화했다.
- 증명사진 placeholder, 기본 정보, 희망 직무, 교육받은 내용, 자기소개 요약, 자기소개 자세히 보기 UI를 추가했다.
- 확인되지 않은 개인정보는 임의로 만들지 않고 추가 예정 / 정리 예정으로 표시했다.

## Changes

- 증명사진 / 기본 정보 영역 추가.
- 증명사진 3:4 비율과 300x400px 또는 360x480px 권장 크기 안내 추가.
- 희망 직무 섹션 추가.
- Profile Summary, Core Skills, Project Experience, Education / Training 섹션 정리.
- 자기소개 요약과 자세히 보기 접기 / 펼치기 UI 추가.
- Links / Contact 섹션 정리.
- Noto Sans KR을 CSS import 방식으로 적용.
- `docs/VERSION_PLAN.md`에 v0.11 계획 추가.

## Verification

- lint: `npm.cmd run lint` 통과
- build: `npm.cmd run build` 통과

## Notes

- 이메일, 학력, 자격증, 증명사진 파일은 임의로 만들지 않았다.
- 기존 프로젝트 상세 페이지는 수정하지 않았다.
