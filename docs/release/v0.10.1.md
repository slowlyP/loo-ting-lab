# v0.10.1 Release Notes

## Version

- v0.10.1 Tech Stack Badge UI

## Summary

- 프로젝트 상세 페이지의 기술스택 중복 표시를 정리했다.
- 상단 기술스택 영역을 아이콘 + 기술명 badge UI로 개선했다.
- 프로젝트 목록 카드도 같은 badge 스타일을 재사용하도록 정리했다.

## Changes

- `react-icons` 설치.
- `TechStackBadges` 공통 컴포넌트 추가.
- ProjectDetail 상단 기술스택 영역에 아이콘 badge 적용.
- ProjectDetail 아래쪽 세로형 `사용 기술스택` 섹션 삭제.
- ProjectCard 기술스택 badge를 공통 컴포넌트로 통일.
- `docs/VERSION_PLAN.md`에 v0.10.1 계획 추가.

## Verification

- lint: `npm.cmd run lint` 통과
- build: `npm.cmd run build` 통과

## Notes

- 프로젝트 설명 문구와 기술스택 데이터 자체는 임의로 변경하지 않았다.
- 외부 로고 이미지 파일은 추가하지 않았다.
