# v0.8 Release Notes

## Version

- v0.8 Design Polish

## Summary

- 전체 포트폴리오의 디자인 톤, 카드 간격, 버튼/링크 표현, 모바일 반응형 가독성을 다듬었다.
- 깨진 한국어 UI 문구를 주요 화면에서 정리했다.
- 기능 구조와 라우팅 구조는 유지했다.

## Changes

- Header nav 문구와 active/hover/focus 스타일 개선.
- Footer 문구와 v0.8 polish 표기 정리.
- Home Hero CTA, Mission Board, 정보 카드 간격 개선.
- Projects 목록과 ProjectCard의 badge / button 가독성 개선.
- ProjectDetail 섹션 제목, 카드 간격, 상태 카드, 산출물 카드 스타일 정리.
- Resume / About / Contact의 카드 스타일과 문구 가독성 통일.
- Contact 링크 버튼 줄바꿈 대응.
- `index.css`에 selection 스타일과 링크 줄바꿈 기본값 추가.

## Verification

- lint: `npm.cmd run lint` 통과
- build: `npm.cmd run build` 통과

## Notes

- 외부 이미지, 영상, 링크는 임의로 추가하지 않았다.
- 개인정보, 이메일, 학력, 경력은 임의로 작성하지 않았다.
- 브라우저 실제 화면 캡처 검증은 v0.9 Release Preparation에서 이어서 진행할 수 있다.
