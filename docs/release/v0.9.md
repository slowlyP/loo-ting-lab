# v0.9 Release Notes

## Version

- v0.9 AI Accident Detection Mini Project

## Summary

- AI Accident Detection을 포트폴리오의 4번째 미니프로젝트 / 팀 프로젝트 카드로 추가했다.
- 기존 대표 프로젝트 3개보다 낮은 비중으로 정리했다.
- README에서 확인한 기능, 역할, 기술스택, 링크만 기준으로 작성했다.

## Changes

- `404 R·N·F AI` 카드 추가.
- `MINI PROJECT / TEAM PROJECT` 분류 추가.
- 기존 ProjectDetail 구조를 재사용한 짧은 상세 정보 추가.
- 송명근의 역할을 조원 / 팀원 기준으로 정리.
- 신고 기능 구현, Google Maps API 연동, AI 탐지 기능 개발 및 서비스 연계 참여를 반영.
- GitHub, YouTube 시연 영상, 발표자료 PDF 링크 추가.
- 프로젝트 자료 섹션의 GitHub 저장소 / 발표자료 PDF 카드를 클릭 가능한 외부 링크로 개선.
- 영상이 있는 경우 시연 영상 버튼을 YouTube 링크로 열 수 있게 유지.
- `docs/VERSION_PLAN.md`에서 v0.9 계획을 수정하고 Release Preparation을 v1.0으로 이동.

## Verification

- lint: `npm.cmd run lint` 통과
- build: `npm.cmd run build` 통과

## Notes

- 역할 표기는 조원 / 팀원 기준으로 정리했다.
- 개인 단독 개발처럼 과장하지 않았다.
- README에 없는 기능이나 성과는 추가하지 않았다.
