# v0.12 Release Notes

## Version

- v0.12 Resume Content Slots

## Summary

- Resume 페이지의 내용을 `src/data/resume.ts`로 분리했다.
- public 폴더에 추가된 실제 증명사진과 수료증 PDF를 Resume 페이지에 연결했다.
- 없는 수료증 파일은 깨진 링크가 아니라 추가 예정 상태로 표시했다.

## Changes

- `src/data/resume.ts` 생성.
- Resume 기본 프로필, 증명사진, 희망 직무, 연락처, 기술 역량, 교육 이력, 수료증, 자격증, 자기소개, 프로젝트 경험 데이터를 분리.
- `/assets/resume/profile/profile-photo.jpg` 증명사진 표시.
- `/assets/resume/certificates/certificate-01.pdf` 수료증 링크 추가.
- `certificate-02.pdf`는 현재 파일이 없어 `파일 추가 예정` 상태로 표시.
- Resume.tsx를 데이터 렌더링 중심으로 정리.
- `docs/VERSION_PLAN.md`에 v0.12 계획 추가.

## Verification

- lint: `npm.cmd run lint` 통과
- build: `npm.cmd run build` 통과

## Notes

- 브라우저 업로드 기능은 추가하지 않았다.
- `public/assets/resume` 파일은 배포 후 공개될 수 있으므로 민감정보가 있으면 반드시 가리고 업로드해야 한다.
- 이메일, 전화번호, 학력, 자격증 내용은 임의로 만들지 않았다.
