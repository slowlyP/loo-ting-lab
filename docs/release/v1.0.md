# v1.0 Release Notes

## Version

- v1.0 GitHub Pages Deploy Preparation

## Deployment URL

- https://slowlyp.github.io/loo-ting-lab/

## Summary

- GitHub Pages 배포를 위한 Vite base 설정과 GitHub Actions workflow를 추가했다.
- 기존 HashRouter 라우팅을 유지해 정적 호스팅 환경의 새로고침 404 위험을 낮췄다.
- Resume PDF 링크를 Vite base에 대응하도록 변경했다.

## Changes

- `vite.config.ts`에 `base: '/loo-ting-lab/'` 추가.
- Resume PDF 경로를 `import.meta.env.BASE_URL` 기반으로 구성.
- `.github/workflows/deploy.yml` 생성.
- README에 GitHub Pages 배포 URL 추가.
- `docs/VERSION_PLAN.md`에 v1.0 GitHub Pages Deploy 준비 내용 추가.

## GitHub Actions Workflow

- main 브랜치 push 시 배포.
- `workflow_dispatch`로 수동 실행 가능.
- `npm ci`, `npm run lint`, `npm run build` 실행.
- `dist` 폴더를 GitHub Pages artifact로 업로드.
- GitHub Pages로 deploy.
