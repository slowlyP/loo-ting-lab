# v0.2 Release Notes

## Goal

Improve the Home screen so the portfolio feels more like a game stage selection project browser.

## Included

- Stronger Hero area with a mission board panel.
- Korean main copy that keeps the v0.1 portfolio direction.
- Stage-select language for the project browser.
- Larger `STAGE 01`, `STAGE 02`, `STAGE 03` emphasis on project cards.
- English project status badges:
  - `COMPLETED`
  - `IN PROGRESS`
  - `DATASET`
- Mobile-friendly responsive grid behavior retained.
