# v1.0.1 Release Notes

## Version

- v1.0.1 Project Tech Stack Audit

## Summary

- 프로젝트별 카드/상세 기술스택을 실제 확인 가능한 기술 중심으로 정리했다.
- 새로 노출되는 기술 라벨에 TechStackBadges 아이콘 매핑을 추가했다.
- 확인되지 않은 기술 후보는 코드에 넣지 않고 문서에만 남겼다.

## Changes

- STACCATO 기술스택 보강:
  - Python, REST API, CCTV / Video Processing, ROI / Rule Engine, AI Media Proxy 추가.
- Wizard Defense 기술스택 정리:
  - Unity 2D 추가.
  - PC / Steam Direction은 기술스택 배열에서 제외.
- Inquiry Dataset 기술스택 보강:
  - Dataset Card, Labeling Guide, Error Analysis, Experiment Log, Test Script 추가.
- 404 R·N·F AI 기술스택 보강:
  - Python, RT-DETR, WebSocket, REST API, File Upload, Route Risk Analysis 추가.
- TechStackBadges 매핑 추가:
  - RT-DETR, WebSocket, REST API, AI Media Proxy, CCTV / Video Processing, ROI / Rule Engine, Unity 2D, Flask-Migrate, Markdown documentation, Dataset Card, Labeling Guide, Error Analysis, Experiment Log, Test Script, File Upload, Route Risk Analysis.
- ProjectCard 기술스택 preview 개선:
  - 카드에서 표시하는 기술스택을 최대 4개에서 8개로 늘렸다.
  - 남은 항목은 `+N modules` badge로 표시한다.
  - ProjectDetail은 제한 없이 전체 기술스택 표시를 유지한다.

## Not Added

- STACCATO SQLAlchemy / ORM: 확인 근거 부족.
- Wizard Defense SpriteRenderer, Animator, TextMeshPro / TMP, Unity UI, Tile / Grid System, ScriptableObject, Coroutine: 확인 근거 부족.
- Inquiry Dataset pytest: 확인 근거 부족.

## Verification

- lint: `npm.cmd run lint` 통과
- build: `npm.cmd run build` 통과

- resume PDF, 인크루트 링크, 이메일, 희망 직무 설정은 유지했다.
- 사진/수료증 직접 노출 제거 상태를 유지했다.
