- Wizard Defense 프로젝트 상세 페이지의 내용틀을 보강한다.
- 인사담당자나 취업 담당자가 Unity와 C#으로 만든 게임 시스템, 기획 구조, 구현 상태를 이해할 수 있도록 정리한다.
- Wizard Defense는 출시 완료 게임이 아니라 플레이 가능 프로토타입 단계의 개인 포트폴리오 프로젝트로 표현한다.

- 이미지와 영상은 확인된 링크가 없으므로 추가 예정 영역으로 표시한다.
