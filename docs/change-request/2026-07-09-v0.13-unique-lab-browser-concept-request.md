## 추가 수정 요청 기록

- Resume 페이지의 증명사진 / 수료증 직접 노출 제거 상태를 유지한다.
- `public/assets/resume/documents/resume.pdf`를 실제 이력서 PDF로 연결한다.
- Resume Document 카드에서 이력서 PDF를 새 탭으로 열 수 있게 한다.
- 인크루트 이력서 확인 링크를 보조 링크로 추가한다.
- Contact 페이지에도 이력서 PDF와 인크루트 이력서 확인 링크를 보조 자료로 배치한다.
- 이력서 PDF는 public assets에 포함되므로 배포 후 URL을 아는 사람이 접근할 수 있다.
- 개인정보가 포함된 PDF는 공개 전 주민등록번호, 생년월일, 주소, 전화번호 등 민감정보가 없는지 반드시 확인해야 한다.

## 추가 수정 요청 기록: 희망 직무 방향 정정

- Resume의 희망 직무 문구를 프론트엔드 중심에서 AI 모델 개발, AI 기반 서비스 구현, Unity 기반 게임 기획·개발 중심으로 수정한다.
- React / TypeScript는 주력 희망 직무가 아니라 AI 결과나 게임 프로젝트를 사용자에게 보여주기 위한 보조 서비스 화면 구현 경험으로 정리한다.
- STACCATO, AI Accident Detection, Inquiry Dataset, Wizard Defense 경험을 희망 직무 방향과 자연스럽게 연결한다.
