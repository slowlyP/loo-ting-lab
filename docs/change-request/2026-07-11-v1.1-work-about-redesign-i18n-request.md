## Goal

Replace the dark Lab Browser presentation with a brighter Work Gallery that prioritizes typography, whitespace, project cards, and readable case studies. Add a Korean/English toggle while retaining HashRouter routes and all confirmed project facts.

## Reason for the visual change

The Lab Browser concept made the portfolio distinctive but gave system decoration more visual weight than the work itself. The v1.1 direction brings project context, contribution boundaries, technology, and evidence forward in a simpler developer-portfolio layout.

## Scope

- Bright Work gallery with CSS-based project visuals where screenshots are unavailable.
- Concise About Me page with interests, process, GitHub, email, and resume access.
- Case-study Project Detail layout.
- Typed `ko` / `en` language context, Korean fallback, and localStorage persistence.
- Project translations keyed by the existing project ID.
- Subtle global canvas network background with pointer response and reduced-motion handling.

## Facts and links that must remain unchanged

- STACCATO, Wizard Defense, Inquiry Dataset, and 404 R·N·F AI project identities and confirmed facts.
- v1.0.1 card and detail technology stacks.
- STACCATO and 404 R·N·F AI remain team participation / architecture understanding / integration-flow descriptions rather than solo ownership claims.
- GitHub, YouTube, presentation PDF, service, and resume URLs.
- `public/assets/resume/documents/resume.pdf` and existing resume links.
- HashRouter paths.

## Translation safety

English copy may translate or condense confirmed Korean copy but must not add unverified technologies, roles, ownership, metrics, or outcomes. Missing localized copy falls back to Korean.

## Technical constraints

- No new library or package changes.
- Do not change `vite.config.ts`, `.github/workflows`, GitHub Pages settings, `package.json`, or `package-lock.json`.
- Language storage key: `loo-ting-lab-language`.
- Invalid stored values fall back to `ko`.
- Canvas uses `requestAnimationFrame`, a capped DPR, fewer mobile points, `pointer-events: none`, and a static reduced-motion mode.
