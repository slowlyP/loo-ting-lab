## 사용자 요청 요약

- Resume 페이지를 취업용 이력서 형태로 고도화한다.
- 증명사진 공간, 희망 직무, Profile Summary, Core Skills, Project Experience, Education / Training, 자기소개 요약, 자기소개 자세히 보기, Links / Contact 섹션을 구성한다.
- 증명사진 실제 파일은 임의로 만들지 않고 placeholder로 표시한다.
- 증명사진 권장 비율은 3:4, 권장 크기는 300x400px 또는 360x480px로 안내한다.
- 자기소개는 처음에는 요약본만 보이고, `자세히 보기` 버튼으로 상세 자기소개를 접고 펼칠 수 있게 한다.
- 이메일, 학력, 자격증, 사진은 임의로 만들지 않고 추가 예정 / 정리 예정으로 표시한다.
- 폰트는 Noto Sans KR 우선 적용을 검토하고, 폰트 파일은 저장소에 직접 추가하지 않는다.
