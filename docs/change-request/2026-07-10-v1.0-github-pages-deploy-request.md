## 사용자 요청 요약

- React + Vite + TypeScript 포트폴리오를 GitHub Pages에 배포할 수 있도록 설정한다.
- 배포 URL은 `https://slowlyp.github.io/loo-ting-lab/`로 준비한다.
- Vite 프로젝트가 저장소 하위 경로에 배포되므로 `base: '/loo-ting-lab/'` 설정을 추가한다.
- 기존 HashRouter 라우팅은 유지한다.
- Resume PDF 링크가 GitHub Pages 하위 경로에서도 깨지지 않도록 `import.meta.env.BASE_URL` 기반으로 구성한다.
- GitHub Actions workflow를 추가해 main 브랜치 push 또는 수동 실행으로 배포한다.
- README와 v1.0 문서를 업데이트한다.
