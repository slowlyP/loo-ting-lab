# Wizard Defense Notion Reference

## 공개 노션 링크

https://three-bluebell-615.notion.site/37eb7dab40e4800e8dbcfad3bbce9f3a

## 사용 목적

이 노션 페이지는 Wizard Defense 프로젝트의 기획, 기능, 스크린샷, 구현 내용, 포트폴리오 설명 작성을 위한 참고자료입니다.

## Codex 참고 규칙

Codex가 Wizard Defense 상세 페이지를 작업할 때는 아래 순서로 참고합니다.

1. 먼저 이 Notion 링크에 접근 가능한지 확인합니다.
2. 접근이 가능하면 기획/기능/스크린샷 내용을 참고합니다.
3. 접근이 안 되면 Notion 링크만으로 내용을 추측하지 않습니다.
4. 확인되지 않은 내용은 구현 완료처럼 쓰지 않습니다.
5. 구현 완료 / 진행 중 / 기획 예정 내용을 구분해서 작성합니다.
6. 포트폴리오 문구는 자연스러운 한국어로 작성합니다.
7. Unity, C#, GitHub, Git LFS 같은 기술명은 영어로 유지해도 됩니다.
