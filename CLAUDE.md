# CLAUDE.md

## Project Context

Loo Ting Lab is a React + Vite + TypeScript portfolio site for a personal
project archive.

The site should feel like a project browser or game stage selection screen,
not a generic resume template.

## Current Version

v0.1 focuses on project setup:

- Tailwind CSS connected through Vite.
- React Router connected with HashRouter.
- Basic pages, components, and project data structure.
- Documentation and worklog files initialized.

## Working Rules

- Work on feature branches, not directly on `main` or `dev`.
- Keep changes scoped to the requested version goal.
- Run `npm.cmd run lint` and `npm.cmd run build` before marking work complete.
- Update `docs/worklog` after code changes.
